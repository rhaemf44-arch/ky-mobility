# DK글로벌 코리아 A안 v2 시안

`concept-a-v2/`는 인계받은 A안(버전 20)을 바탕으로 디자인을 개선한 시안입니다.

## 실행
영상·이미지는 저장소에 없습니다. 인계 ZIP의 `dist/concept-a/assets/` 파일을 `concept-a-v2/assets/`에 복사한 뒤 실행하세요.

```sh
python3 -m http.server 8000
# http://localhost:8000/concept-a-v2/
```

파일이 없어도 화면은 깨지지 않고 어두운 배경으로 표시됩니다(`preview/` 캡처가 이 상태입니다).

## 바뀐 점
- 시안 표시 제거: 상단 비교 바, 기존 A안 링크, 디자인 비교 링크, 하단 시안 문구
- 연락 수단 상시 노출: 헤더 전화·상담 버튼, 모바일 하단 전화+상담 바(영상 구간에서도 표시), 상담 섹션 빠른 상담 카드
- 글자 크기: 본문 15~17px, 작은 라벨 11~13px 이상
- 영상 스크롤 구간: PC 480svh → 300svh, 모바일 427svh → 280svh, "건너뛰기" 버튼 추가
- 요금표(맞춤 견적 27칸) → 견적 기준 5가지 카드
- 차량 카드 9대 통일 + 탑승 인원·수하물 칸 추가
- 금색·배경색·영문 부제(VIP CHAUFFEUR · DAEGU) 통일
- 상담 폼에 항공편·열차 번호 항목 추가, 차량 소개에서 넘어오면 선택 안내 문구 표시
- 쓰지 않는 CSS 정리(단일 style.css)

영상 동기화 로직(motion.js)은 기존 그대로 유지했습니다.
